What improved

  • routine over-triage cut sharply — 42 → 26 routine calls wrongly escalated to urgent (routine recall +17 pts). The rubric boundary rules did their job.
  • insufficient-detail now perfect — 100% flagged, 0 guessed (was 95.5%). §4's minimum-information-set rule + degraded examples.
  • unnecessary interrupts down — 45 → 33.

What regressed

  • The cost bias over-escalated — "err toward higher acuity" pushed ~19 borderline calls (14 urgent, 4 fyi, 2 routine) up to critical, without catching one extra true critical (recall stayed 91.1%).
  • urgent tier destabilised — recall 95.3% → 77.6%.
  • Overall accuracy −1.4; cost-weighted error 633 → 649.
Takeaway. Feeding the assets in helped where they were specific (boundary rules → routine; §4 → insufficient-detail) and hurt where the nudge was global (the cost bias → over-escalation to critical). This tradeoff is invisible to intuition — it looks like an obvious win — and is only visible because the evaluation harness measured it. Recommendation: drop the cost bias, keep the rubric rules + labelled examples, and re-run to confirm a cleaner result.
Held-out test n=280; frozen gpt-5-mini; identical corpus and split. Synthetic data — validates the pipeline and tunes the prompt, does not establish real-world accuracy (generator and classifier share a model family). Cost values in data/costs.yaml are placeholders (N4).
