What it means

  • Critical detection strong & stable — 91.1%; the 5 misses land as urgent/routine, never fyi.
  • Routine over-triage fixed — 42 → 25; routine recall 37% → 58%. The rubric boundary rules did this.
  • Clean accuracy up to 83.2%; insufficient-detail flagging perfect.
  • Residual: urgent under-triage — urgent recall 84.7% (was 95.3%); 7 genuine urgents demoted to routine. This is the next target.
  • Degraded transcripts still hard — 63.1% vs 83.2% clean. Prompt changes haven't moved this slice.

Limitation
Generator and classifier share a model family, so these synthetic results validate the pipeline and tune the prompt; they do not establish real-world accuracy. Human-vs-assigned label agreement is 77.5% — some "errors" may be label disagreements. Rubric §1 awaits partner-physician sign-off; cost values are placeholders (N4).
